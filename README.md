# Human_Stress_Detection-Using_Machine_Learning
<h3 align="center">This project originally developed in 2023</h3>
Detect stress in real-time for healthcare and interview scenarios. This web app uses a CNN-based facial recognition system to analyze live webcam feeds and images for high stress levels. By identifying emotional distress early, it aims to proactively reduce severe mental health outcomes like depression during high-pressure events.
